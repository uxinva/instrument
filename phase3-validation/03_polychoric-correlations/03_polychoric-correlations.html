Polychoric correlations — SUS, UEQ, Cognitive value, Intuitiveness, Visualization

Item groups

  • SUS: SUS_1–SUS_10
  • UEQ_pragmatic: UEQ_1–UEQ_4
  • UEQ_hedonic: UEQ_5–UEQ_8
  • Cognitive_value: P064, P301, P060, P027
  • Intuitiveness: P088, P026, P4026A
  • Visualization: P106, P089, P098, P097, P022A, P067

The complete polychoric matrix is calculated item by item (including, in this instance, pairs within the same construct), organized by construct blocks in the previously indicated order. Subsequently, a hierarchical cluster analysis is performed on this same matrix to verify whether the items group together empirically as hypothesized by the six intended constructs or if the data suggest a different structure. This notebook is run twice, set by the scales parameter: uxvis uses only the items of the UXVis scale (this run is used by step 04), and all also includes the gold-standard items (SUS and UEQ-S).

Compute polychoric correlations (pairwise deletion)

hetcor(..., use = "pairwise.complete.obs") estimates each pairwise correlation from only the rows where that specific pair of items is non-missing (pairwise deletion), rather than dropping a participant from the whole matrix because a single item elsewhere is missing. Every item is coerced to an ordered factor first, so every pair is estimated as a genuine polychoric correlation (not Pearson or polyserial).

std.err is left off: computing polychoric standard errors requires a numerical Hessian, and its finite-difference probing routinely pushes the bivariate-normal CDF differences into underflow, producing "NaNs produced" warnings across most pairs. The r estimates themselves are unaffected — only that Hessian step is unstable. Significance is instead approximated below with the same t-approximation used for Pearson correlations (t = r * sqrt(n-2) / sqrt(1-r^2), df = n-2); this is a standard practical stand-in for polychoric significance testing, not an exact analytic result.

SUS_2, SUS_4, SUS_6, SUS_8, SUS_10 are the negatively-worded SUS items (Brooke, 1996) — on the 1–5 raw scale, a higher raw score means worse usability for these five, opposite every other item in the matrix. They’re reverse-coded (6 - score) before scoring, so every item in the resulting matrix points the same “more positive” direction and signs are directly comparable across the whole matrix (matches the reverse-coding already applied to the SUS composite in the Pearson notebook).

reverse_items <- c("SUS_2", "SUS_4", "SUS_6", "SUS_8", "SUS_10")

# Compute the correct pairwise sample size matrix (N)

n_mat <- t(valid_data) %*% valid_data
dimnames(n_mat) <- dimnames(r_mat)

# Approximated t-test and p-values
t_mat <- r_mat * sqrt(n_mat - 2) / sqrt(1 - r_mat^2)
p_raw <- 2 * pt(-abs(t_mat), df = n_mat - 2)
p_mat <- matrix(p_raw, nrow = nrow(r_mat), ncol = ncol(r_mat), dimnames = dimnames(r_mat))
diag(p_mat) <- NA

groups_vec <- item_to_group$group[match(colnames(r_mat), item_to_group$item)]

Hierarchical clustering of items

Distance is 1 - r: items that move together are placed close together. Now that the negatively-worded SUS items are reverse-coded, r is directly comparable in sign across the whole matrix, so the plain (non-absolute) distance is the right one to use. This is agnostic to construct labels; it is purely data-driven, then compared against the intended construct assignment.

dist_mat <- as.dist(1 - r_mat)
hc <- hclust(dist_mat, method = "average")

k <- length(item_groups)
empirical_cluster <- cutree(hc, k = k)

plot_dendrogram <- function() {
  if (requireNamespace("dendextend", quietly = TRUE)) {
    dend <- as.dendrogram(hc)
    label_order <- labels(dend)
    dend <- dendextend::set(dend, "labels_col",
                             group_colors[groups_vec[match(label_order, colnames(r_mat))]])
    dend <- dendextend::set(dend, "labels_cex", 0.8)
    plot(dend, main = "Hierarchical clustering of items (distance = 1 - r)")
    legend("topright", legend = names(group_colors), fill = group_colors,
           cex = 0.7, bty = "n")
  } else {
    plot(hc, hang = -1, xlab = "", sub = "",
         main = "Hierarchical clustering of items (distance = 1 - r)")
    mtext("install.packages('dendextend') for construct-colored labels", side = 1, cex = 0.7)
  }
}
