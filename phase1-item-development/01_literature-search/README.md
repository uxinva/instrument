# Step 01: Literature search

To be documented. Keyword search in the full texts of IEEE VIS papers extracted with GROBID (TEI XML), based on the notebook by Petra Isenberg and Tingying He (2021), edited by Anne-Flore Cabouat (2023) and by Eliane (2024).

Query used (two blocks joined by AND; terms inside a block joined by OR, case-insensitive substring match):

- UX terms: "user experienc", " UX ", "usability", "experience using", "experience of interacting", "experience of using", "experience with the system", "experience with the tool", "interactive experience", "experience working with"
- Evaluation terms: "likert", "question", "metric", "interview", "eval", "assess", "user study", "usability study", "participant", "expert", "end user", "recruit"

Input: the GROBID XML corpus (`Vis-all_full_paper_pdfs-text-extraction-results`), kept on the team NAS and not in this repository.
