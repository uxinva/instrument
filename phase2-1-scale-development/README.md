# Phase 2.1: Scale development

> **Status:** started on 2026-11-12. The steps are being documented.

This phase produces the **65-item, three-factor exploratory factor analysis (EFA)** solution that the [item reduction phase](../phase2-2-item-reduction/README.md) starts from.

- **Data:** 65 items rated by 506 participants (Gephi, Power BI, Qlik, Tableau, JMP).
- **Context:** decisions, reference results and pending points are in [`scale-development-context.md`](scale-development-context.md).

The steps will follow the layout of the other phases: a `data/` folder and numbered steps `NN_step-name/`, each with a README, a notebook or scripts, the rendered report and an `output/` folder.
